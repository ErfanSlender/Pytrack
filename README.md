# 🐍 PyTrack

A Personal Finance Tracker built with Python

## 📌 About

PyTrack is a command-line
appliaction
for managing personal income and expense.

## ✨ Features

- Add income
- Add expense
- Track balance
- Save data using JSON
- Handle errors

## 🛠️ Technologies

- Python
- JSON
- Git
- GitHub

##  🚀 Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Go to the project directory:

    cd Pytrack

Run the appliaction:

    python main.py
